# infNote Windows 便携版

1. 将整个 ZIP 解压到一个文件夹。
2. 双击 `infNote.exe`，程序会启动本地服务并自动打开浏览器。
3. 保留程序的控制台窗口；停止使用时，等待页面显示“所有更改已保存”，然后关闭控制台，或按 Ctrl+C 停止。

无需安装 Python 或 Node.js，运行时无需联网。需要 Windows 10/11 x64 和现代浏览器。
必须保留 EXE 旁的 `_internal` 文件夹，不能只复制 EXE，也不要在压缩包预览中直接运行。

## 笔记保存位置

默认在 `%USERPROFILE%\infNoteData`，页面左下角可复制实际路径。
“便携版”表示解压即用，笔记仍保存在用户目录，不随软件文件夹移动。
升级时解压新版本即可，笔记保持不变。关闭程序后复制整个数据目录即可备份。
不要将自己的笔记数据放入公开发布的压缩包。

再次启动时，如果原程序仍在运行，会直接打开已有画布。
如果其他程序占用 8765 端口，请先关闭冲突程序。

此版本没有代码签名，首次运行可能出现 Windows 信誉提示。请从项目自己的 Release 下载，并根据 `.sha256` 文件核对来源和完整性；组织管理的设备请遵循其软件运行要求。
